Request lifecycle

How to read the numbers. This is a deterministic teaching model, not a GPU benchmark. Prefill becomes more efficient at larger token batches; every engine step has launch/scheduling overhead; decode is protected first; paged KV grows on demand while “reserved” KV claims each request’s maximum length up front. Use it to reason about mechanisms and trends, then measure the real engine on target hardware.
