How to read this example

The model has two conceptual parameter partitions, θ₀ and θ₁; their optimizer states are s₀ and s₁. DDP shows each tensor as a single full bar. In the sharded strategies, each bar is divided into two equal conceptual partitions; a filled segment is present on that rank. Colors identify partitions, not exact memory sizes. Primes mark updated parameters. Gradient superscripts identify the rank's local contribution. The two ranks start with the same weights and optimizer state.

partition 0partition 1

Teaching model: fixed two-rank, equal-weight gradients and one optimizer update. Full sharding illustrates an FSDP-style full-shard policy that keeps parameters materialized through backward; actual implementations can reshard, gather and overlap at different times. The phases separate computation and synchronization for teaching; in DDP, bucket reductions can overlap backward. Activation and temporary-buffer memory are not shown.
