# Session 4 — Train a small GPT

## Purpose

Run the first complete experiment and learn to distinguish healthy training from
an implementation or optimization failure.

## Key ideas

- initialization and optimization recipe;
- training and validation curves;
- checkpoint selection;
- sampling as a qualitative diagnostic.

## Practical task

Train the course model on the prepared dataset, inspect its behavior and save a
baseline checkpoint.

## Expected output

A reproducible baseline run with configuration, curves, checkpoint and sample
generations.

## Material to add later

- reference configuration;
- experiment checklist;
- example healthy and unhealthy curves;
- sampling script.
